# Практическая работа 3. Строки в объекты и ошибки ограничений

Занятие: [Строки в объекты и ошибки ограничений](https://algorthimization-course-vvodnoe.vercel.app/mdk0111-ado-net/lessons/03-obekty-i-oshibki/index.html), раздел «Практика».
Условия всех четырёх заданий в тексте — [`tasks.md`](tasks.md).
Задания 1–3 выполняются на странице занятия, задание 4 — в проекте `ItemsApp` из этой папки.

## Запуск

```bash
docker compose up -d          # в корне репозитория
cd practice/03-items/ItemsApp
dotnet run
```

Заготовка добавляет позицию в заказ 1 и завершается на второй попытке с ошибкой 23505.
Программу можно запускать много раз: в начале она удаляет позицию, которую добавляет сценарий.

## Задание 4

1. В `AddItemAsync` перехватить ошибки 23505, 23503 и 23514 и вернуть тексты из условия на странице занятия.
2. В `GetItemsAsync` создать `OrderItemRow` из текущей строки, читая столбцы по имени через `GetOrdinal`.

Ожидаемый вывод после исправления:

```text
Добавлено строк: 1
Товар 4 уже есть в заказе 1.
Заказа 1 или товара 99 нет в базе.
Количество должно быть больше нуля, указано 0.
Позиции заказа 1:
  Клавиатура: 1 × 2490,00 руб.
  Мышь: 1 × 890,00 руб.
  Наушники: 1 × 3290,00 руб.
```

Разделитель в суммах зависит от языка системы: запятая или точка.
