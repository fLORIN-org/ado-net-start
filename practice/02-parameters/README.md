# Практическая работа 2. Параметры запроса и SQL-инъекция

Занятие: [Параметры запроса и SQL-инъекция](https://algorthimization-course-vvodnoe.vercel.app/mdk0111-ado-net/lessons/02-parametry/index.html), раздел «Практика».
Условия всех четырёх заданий в тексте — [`tasks.md`](tasks.md).
Задания 1–3 выполняются на странице занятия, задание 4 — в проекте `SearchApp` из этой папки.

## Запуск

```bash
docker compose up -d          # в корне репозитория
cd practice/02-parameters/SearchApp
dotnet run
```

Программа спрашивает текст поиска, печатает отправленный SQL-запрос и найденные товары.
Если цены в базе изменились после опытов с `UPDATE`, база возвращается к исходным строкам:
`docker compose down`, затем `docker compose up -d`.

## Задание 4

Запустить заготовку с вводом `' OR 1=1 --` и убедиться, что выводится вся таблица.
Исправить `SearchApp/Program.cs`: передать шаблон поиска параметром `@pattern`
через `command.Parameters.AddWithValue`. Проверить исправленную программу вводами `' OR 1=1 --` и `USB`.
