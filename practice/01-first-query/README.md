# Практическая работа 1. Первый запрос к базе из C#

Занятие: [Первый запрос к базе из C#](https://algorthimization-course-vvodnoe.vercel.app/mdk0111-ado-net/lessons/01-pervyy-zapros/index.html), раздел «Практика».
Условия всех четырёх заданий в тексте — [`tasks.md`](tasks.md).
Задания 1–3 выполняются на странице занятия, задание 4 — в проекте `OrdersApp` из этой папки.

## Запуск

```bash
docker compose up -d          # в корне репозитория
cd practice/01-first-query/OrdersApp
dotnet run
```

Заготовка печатает 12 заказов: номер, статус и сумму.

## Задание 4

Изменить запрос в `OrdersApp/Program.cs`: вывести только новые заказы (`status = 'new'`)
с именем клиента из таблицы `customers` и суммой. После списка напечатать `Новых заказов: N`.
Подробное условие и подсказки — на странице занятия.
