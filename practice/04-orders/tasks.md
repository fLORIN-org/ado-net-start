## Задание 1. Порядок вызовов в транзакции · 2 балла

Шесть строк метода, который оформляет заказ в транзакции, перемешаны:

```csharp
await insertItem.ExecuteNonQueryAsync();
await using var transaction = await connection.BeginTransactionAsync();
await transaction.CommitAsync();
await using var connection = await dataSource.OpenConnectionAsync();
await takeStock.ExecuteNonQueryAsync();
int orderId = (int)(await insertOrder.ExecuteScalarAsync())!;
```

**Что нужно сделать.** Расставить строки в том порядке, в котором они выполняются при успешном оформлении.

## Задание 2. Что останется в базе · 3 балла

В исходной базе 12 заказов. Каждый случай выполняется на исходной базе и пытается оформить
один заказ из двух позиций: монитор (1 шт.) и веб-камеры (20 шт.), веб-камер на складе 9.

1. Без транзакции. Ошибка 23514 на последнем `UPDATE`, программа её перехватила.
2. В транзакции. Ошибка 23514 на последнем `UPDATE`, в `catch` вызван `RollbackAsync`.
3. В транзакции. Все команды прошли без ошибок, но `CommitAsync` не вызван.
4. В транзакции. Ошибку 23514 на первой позиции перехватили и выполнили команды второй позиции без точки сохранения.
5. В транзакции. Ошибку 23514 на последнем `UPDATE` перехватили и вызвали `CommitAsync`.
6. В транзакции с точкой сохранения перед каждой позицией. Вторая позиция откатилась к точке, в конце вызван `CommitAsync`.
7. В транзакции. Все команды прошли, вызван `CommitAsync`.

Варианты: заказов 12, заказов 13, исключение 25P02.

**Что нужно сделать.** Для каждого случая выбрать результат.

## Задание 3. Что прочитает другое соединение · 2 балла

На складе 9 веб-камер. Соединение 1 открывает транзакцию и выполняет
`UPDATE products SET stock = stock - 3 WHERE id = 5`. Соединение 2 читает
`SELECT stock FROM products WHERE id = 5`.

1. Соединение 1 читает остаток внутри своей транзакции, после `UPDATE`.
2. Соединение 2 читает, пока транзакция не завершена.
3. Соединение 2 читает после `COMMIT`.
4. Транзакция завершилась `ROLLBACK`. Соединение 2 читает.

Варианты: 9, 6, 3.

**Что нужно сделать.** Для каждого момента выбрать, какой остаток будет прочитан.

## Задание 4. Транзакция в OrderApp · 3 балла

Приложение `OrderApp` оформляет два заказа. Второй не проходит, но в базе остаются его строка,
позиция с мышами и списанные мыши: в строке «Стало» 14 заказов, мышей в остатках 38.

1. Запустите базу и программу.

   ```bash
   docker compose up -d                  # в корне репозитория
   cd practice/04-orders/OrderApp
   dotnet run
   ```

2. В `CreateOrderAsync` откройте транзакцию сразу после открытия соединения, сохраните её после цикла
   по позициям и откатите в блоке `catch`. Передайте транзакцию третьим аргументом во все три `NpgsqlCommand`.
3. Запустите программу. Весь вывод вставьте в поле задания 4 на странице занятия.

Подсказка: транзакция объявляется так — `await using var transaction = await connection.BeginTransactionAsync();`.
