# Практическая работа 4. Транзакции и откат операций

Занятие: [Транзакции и откат операций](https://algorthimization-course-vvodnoe.vercel.app/mdk0111-ado-net/lessons/04-tranzakcii/index.html), раздел «Практика».
Условия всех четырёх заданий: [`tasks.md`](tasks.md). Задания 1–3 выполняются на странице занятия,
задание 4 — в проекте `OrderApp` из этой папки.

## Запуск

```bash
docker compose up -d          # в корне репозитория
cd practice/04-orders/OrderApp
dotnet run
```

Программа оформляет два заказа. Второй не проходит: веб-камер на складе 9, а заказано 20.
В начале программа возвращает заказы и остатки к строкам из `init.sql`, поэтому её можно запускать много раз.

## Задание 4

Выполнить оформление заказа в `CreateOrderAsync` в одной транзакции: открыть транзакцию после открытия
соединения, сохранить её после цикла по позициям, откатить в блоке `catch`.

Ожидаемый вывод после исправления:

```text
Было: заказов 12, позиций 18
Заказ 1: оформлен, позиций 2.
Заказ 2: не оформлен, на складе не хватает товара.
Стало: заказов 13, позиций 20
Остатки: Клавиатура 13, Мышь 40, Монитор 24" 5, Веб-камера 9
```
