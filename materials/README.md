# Материалы занятий

Файлы, которые раздаются на занятиях: SQL-скрипты, данные, памятки.
Архивы с проектами в папку не кладутся: их файлы уже лежат в репозитории, а README папки занятия называет папки, в которых они лежат.
Папку ведёт преподаватель. Новые файлы GitHub переносит сюда раз в сутки (см. [`docs/UPDATES.md`](../docs/UPDATES.md)).
Свои файлы в эту папку не кладите: при обновлении они не удалятся, но их перепутают с раздаточными.

| Папка | Занятие | Что внутри |
|---|---|---|
| [`lesson-00-setup`](lesson-00-setup/README.md) | 0. Установка .NET 10 SDK и Docker | где в репозитории лежат файлы архива `orders-starter.zip` |
| [`lesson-01-first-query`](lesson-01-first-query/README.md) | 1. Первый запрос к базе из C# | где лежат файлы архива `orders-starter.zip` |
| [`lesson-02-parameters`](lesson-02-parameters/README.md) | 2. Параметры запроса и SQL-инъекция | где лежат файлы архива `search-app.zip`, вводы для опытов с инъекцией |
| [`lesson-03-items`](lesson-03-items/README.md) | 3. Строки в объекты и ошибки ограничений | где лежат файлы архива `items-app.zip` |
| [`lesson-04-orders`](lesson-04-orders/README.md) | 4. Транзакции и откат операций | где лежат файлы архива `order-app.zip` |
